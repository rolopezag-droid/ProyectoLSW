# FMP agotado incluso con un ticker

Diagnóstico real: profile AAPL devuelve HTTP 429 y Limit Reach. La aplicación no puede restablecer la cuota del proveedor. Se aislará un cliente FMP con pausa compartida por credencial, lecturas secuenciales, deduplicación y caché por recurso exitoso, evitando que una respuesta parcial quede congelada seis horas. El universo público dejará de consumir FMP. Se preservará el contrato de fundamentales y la selección posterior al Top.
