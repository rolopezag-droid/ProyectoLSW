# Diseño
Actual: O(pares * escenarios * log escenarios), con semilla independiente por spread. Alternativa: ampliar timeout, conserva coste y no resuelve raíz. Aplicado: muestra común por comparación, ordenada una vez; sumas prefijas para media y búsquedas para frecuencia/percentiles, O(escenarios log escenarios + pares log escenarios). Frontera de dominio research-analysis.js; Worker y API conservan contratos. Se mantiene semilla individual en llamadas independientes. En comparación se documenta semilla común y mismo horizonte temporal: diferencias numéricas frente a sorteos anteriores son esperables, sin afirmar igualdad entre muestras distintas.
